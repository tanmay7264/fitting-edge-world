# Fitting Edge · Phased GTM in 3D

Interactive 3D prototype of the Fitting Edge go-to-market plan (Seed → Expand → Scale). A customer and a plumber walk the road and step inside each of the 12 buildings, which open up (roof lifts, walls fade) to show a 3-step scene. A branded van drives the road and people chat outside. Room scenes live in `interiors.js`.

- Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000
- Edit content: change `world.config.js` and reload (zone order = walk-through order)
- Deep link to a building: `#lab`, `#plumbers`, `#b2b`, …
